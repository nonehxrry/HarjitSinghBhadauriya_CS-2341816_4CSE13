``` text
                        │

```

### Workflow Overview

1.  **Develop** --- Implement backend features and REST APIs using Java
    and Spring Boot.
2.  **Version Control** --- Push code changes to the Git repository.
3.  **Continuous Integration** --- GitHub Actions automatically triggers
    the CI/CD pipeline.
4.  **Containerization** --- Application services are packaged into
    Docker containers.
5.  **Deployment** --- Containerized backend services are deployed on
    AWS EC2.
6.  **Database Layer** --- Spring Boot services interact with optimized
    PostgreSQL databases.
7.  **Quality Assurance** --- Unit, integration, and API contract tests
    help maintain reliability.
